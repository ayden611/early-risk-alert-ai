# Epic / FHIR Integration Boundary Lock

## Governance Status
**Locked for future discovery only**

## Current Boundary
Early Risk Alert AI is not currently integrated with Epic or any live hospital EHR environment.

No live PHI flow, production endpoint, hospital credential, write-back function, autonomous escalation function, interruptive alert mechanism, or bedside-monitoring replacement is active.

## Permitted Activities
The following activities are permitted:

- conceptual architecture documentation;
- synthetic-data field mapping;
- retrospective de-identified planning;
- sandbox-only planning;
- workflow discovery discussions;
- hospital-side requirements gathering;
- security and privacy checklist development.

## Prohibited Activities Without Formal Authorization
The following activities are not authorized:

- connecting to a hospital production endpoint;
- requesting or storing hospital credentials;
- processing live patient data;
- transmitting PHI;
- writing back to an EHR;
- deploying interruptive EHR alerts;
- activating autonomous escalation;
- representing Epic integration as active;
- making new public claims;
- modifying the current 513(g) package based solely on an informal conversation.

## Escalation Gate
Before any live or hospital-connected technical work, require documented review of:

1. institutional workflow scope;
2. privacy and security requirements;
3. contractual requirements;
4. data-use authorization;
5. interface method;
6. clinical-operations requirements;
7. usability requirements;
8. regulatory implications;
9. approval authority;
10. pilot agreement scope.
